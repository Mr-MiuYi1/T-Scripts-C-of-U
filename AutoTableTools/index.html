1

安装 Tampermonkey

按浏览器选择安装渠道，安装完成后确认扩展已启用。

2

安装工具脚本

点击下方按钮，在油猴打开的安装页面中确认脚本名称， 然后点击“安装”；已安装时按页面提示更新或重新安装。

安装 AutoTable 工具集↗ 安装 AutoTable 工具集(从GitHub获取)↗

安装完成后回到脚本支持的 AutoTable 页面并刷新。 页面出现工具悬浮球后，点击打开菜单即可开始使用。

01

工具概览与快速上手

先了解工具适用范围，再完成第一次操作。

AutoTable 工具集是运行在 AutoTable 页面上的油猴用户脚本，集中增强表格复制、字段组合、左右列置顶、工单进展、文本编辑、搜索历史和文档操作。作者为 MiuYi。本说明书依据附件 AutoTabletools.user(5).js 的实际实现编写，脚本元数据与核心版本均为 V7.20.0。

它依赖 AutoTable 原页面、已登录会话和当前账号权限。表格视图与文档视图的功能分别出现；没有识别到表格、未选择单元格或没有已选记录时，相关入口可能不可用。

适用条件 说明
运行地址 http / https://115.190.74.246/* 与 http / https://106.54.31.31/*。附件未配置其它域名。
安装方式 在支持用户脚本的浏览器和脚本管理器中安装该 .user.js 文件，保存并启用，然后刷新匹配的 AutoTable 页面。
更新配置 脚本声明了 GitHub raw 的 @updateURL 与 @downloadURL；更新检测由脚本管理器处理，取决于网络与管理器设置。
本地记忆 设置主要通过用户脚本存储保存。切换浏览器或脚本管理器后，使用 JSON 设置备份迁移；不是账号云同步。
  1. 打开 AutoTable 表格，点击悬浮球，或按 Alt+T 打开工具菜单。
  2. 普通单击一格建立聚焦；按住 Alt 单击复制该格。
  3. 进入“表格 → 字段组合”，检查默认“商业常用信息”的字段是否对应当前表。
  4. 按住 Ctrl 单击一格，复制同一行的当前字段组合。
  5. 需要固定字段时，进入“表格 → 列置顶”开启总开关，并选择字段的左侧或右侧。
  6. 配置完成后，在“设置 → 备份”导出全部设置，留存一份可恢复的 JSON。
版本判断以附件顶部 @version 和核心 APP.version 为准。脚本中存在较早的模块版本与历史注释，它们不表示整个工具仍是旧版本。
02

悬浮球与四区菜单

用一个入口完成高频工作，并按场景进入不同工具。

区域 内容 出现条件
快捷 当前工作上下文、复制当前格、复制字段组合、复制整行、批量追加进展、聚焦和高亮状态、规则组切换、短语与搜索记录入口。 一般页面；具体动作按上下文启用。
表格 二级入口为字段组合与列置顶；负责当前表绑定、字段管理和全部表字段管理。 需要识别到表格才可配置实际字段。
文档 导航与书签、查找替换开关、文档表格增强和健康检查。真正查找操作在文档页内。 AutoTable 文档视图。
设置 悬浮球、表格、外观、编辑、备份、快捷键等分区及独立模块设置。 通用设置入口。

移动、尺寸与定位

悬浮球可自由拖动，松手后吸附到最近的左右边缘并记住位置；5 秒无操作后变为半透明，鼠标靠近恢复。默认大小 48 px，可在 38–72 px 范围调整，也可恢复默认位置。

菜单弹出方向支持自动、向左、向右、向上和向下。自动模式依据真实菜单尺寸与视口余量选择位置；窗口较小时面板限制高度并内部滚动。打开菜单后按四区任务导航，设置页可用顶部快速导航跳转。

当前工作上下文

快捷页显示当前表、当前字段与内容摘要，以及正在使用的字段组合。切换表、视图或单元格时会同步更新；长内容只在摘要中截短，不代表实际复制值被截短。页面加载期间会合并刷新，编辑字段组合时保留会话草稿，降低重绘打断输入的可能。

03

智能复制与行列聚焦

普通点击定位，修饰键点击复制，双击保留原生编辑。

操作 结果 前提
普通单击单元格 聚焦当前格，可同时强调所在行、列和列表头；不自动复制。 聚焦模式已开启。
Alt + 单击 复制当前单元格内容。 智能复制已开启。
Ctrl + 单击 复制当前行的指定字段组合。 智能复制已开启，并已设置当前字段组合。
Alt+R 复制当前整行。 已选择当前行单元格。
Alt+V 复制“字段名：内容”。 已选择单元格。
双击 保留原页面单元格编辑流程；第二次 click 不再执行 Alt / Ctrl 复制。 字段有编辑权限。

聚焦子开关

可单独关闭行高亮或列高亮，仅保留当前格突出显示；快捷页提供清除聚焦入口。Alt+F 切换聚焦模式，Alt+C 切换智能复制。

虚拟滚动中的表现

工具分别记忆记录身份和字段 ID。原行离开可见区域又返回时恢复聚焦；视图或路由变化后丢弃旧身份，避免误高亮同号记录。横向滚动使字段暂时不可见时，不会改为聚焦其它字段。左右置顶列使用不透明底层，防止后方内容透出。

“复制整行”受当前页面可识别字段与单元格影响，不等同于后台全字段导出。空白格、未加载或隐藏字段不能据此推断后台一定没有值。
04

字段组合与当前表绑定

一次选择多字段，输出适合聊天、通知或 Excel 的内容。

  1. 进入“表格 → 字段组合”，新建或编辑组合，填写名称。
  2. 选择“当前表字段”或“通用模板”。当前表字段使用稳定字段 ID；通用模板使用字段名称及常见别名匹配。
  3. 搜索并勾选需要的字段，支持全选和清空；检查所选字段与当前表是否兼容。
  4. 选择输出格式并保存。把组合设为 Ctrl + 单击使用的组合，或为它录制专属快捷键。
  5. 回到数据表点击某行，再执行 Ctrl + 单击或“复制字段组合”。
格式 输出特点 适合场景
竖线 值之间使用 | 。 聊天中转发多个字段。
空格 以空格分隔。 简短通知。
Tab 字段之间为制表符。 粘贴到 Excel / WPS 的多列。
自定义 自定义分隔符，如 / 、 → 。 按工作话术组织内容。
分行 每行输出“字段名：内容”。 正式说明或完整信息卡。

绑定优先级与兼容提示

当前实际表专用配置优先于通用模板。没有专用配置时，按模板名称和常见别名匹配字段；面板显示当前表、自动匹配、部分匹配或不兼容等状态。不同表有同名字段也不会串用当前表的字段 ID 配置。清除当前表配置后可回到通用模板匹配。

默认组合为“商业常用信息”：商业编码、商业名称、商务、商业采购联系方式，默认用竖线分隔。实际表缺少这些列时应自行调整。

快速切换

Alt+Q 下一组合，Alt+Shift+Q 上一组合，Alt+X 打开选择器。选择器中可按 1–9 选择前九个组合，按 Esc 关闭。当前表的活动组合可独立记忆。

编辑器在切换“当前表字段 / 通用模板”、重新读取字段时同步会话草稿，保留名称、格式、勾选与搜索内容。最终以保存配置为准；草稿保护不等于永久自动保存。

05

左右列置顶与列宽记忆

把关键字段固定在两边，并按实际表独立保存。

  1. 进入“表格 → 列置顶”，打开“表列置顶”。
  2. 在字段列表搜索名称，对字段选择“左 / — / 右”。左固定到最左侧，右固定到最右侧，—取消置顶。
  3. 横向滚动验证关键字段始终可见。需要时拖动原生列表头边界调整宽度。
  4. 保留“记住置顶列列宽”开启状态，拖动结束后记录最终宽度；再次打开同表、切视图或重新置顶时恢复。

按表保存，按视图显示

置顶方向与列宽按“实际表 + 字段 ID”保存，不按视图另存一套。切换另一张表自动使用另一张表配置；同表某个视图隐藏已置顶字段时，该列不会强行显示，面板可提示当前视图隐藏数量。编辑和虚拟滚动重绘后工具会恢复置顶层级与偏移。

快捷表头置顶

开启独立开关后，单击表头执行左置顶 / 取消，Shift + 单击执行右置顶 / 取消。筛选按钮、字段菜单、排序控件和原生列宽拖动仍保留各自操作。Alt+Shift+K 切换此功能；Alt+P 切换置顶显示；Alt+Shift+P 打开置顶设置。

维护入口 作用
重新应用 重新计算并应用当前表置顶。
清除列宽记忆 清除当前表保存的宽度，让列宽回到原页面当前状态。
清空当前表 清理当前表置顶配置。执行前检查确认内容。
管理全部表字段 集中查看已记忆表、字段与配置；支持查找、调整置顶、宽度及清理配置。已读取字段不必先置顶才纳入目录。
全部表字段管理可按表名称 / ID 查找；字段按全部、左置顶、未置顶、右置顶、有列宽记忆筛选，支持单字段“清宽”、左 / — / 右切换。当前表可同步字段和重新应用；每表可全部设为不置顶、清除列宽或删除整份配置。删除整份配置会丢弃目录与设置，不会删除后台业务表。

全部表字段管理是脚本已记忆的字段目录，不是对所有后台表进行完整扫描。“+ 添加列”仍位于原生字段末端，随表头滚动，不作为置顶字段。

表格视觉样式中心

设置页可独立自定义置顶边界、当前格、行高亮和列高亮。各组自定义初始关闭；开启某组后调整颜色、透明度、线宽与柔光强度，实时预览。置顶边界采用边缘与阴影，当前格采用轮廓和柔光，行列使用独立叠色，减少互相覆盖。

样式组 可调整内容
置顶边界 颜色、边界宽度、阴影强度。
当前格 颜色、填充透明度、轮廓宽度、柔光强度。
行高亮 颜色、透明度、边缘宽度、柔光强度。
列高亮 颜色、透明度、边缘宽度、柔光强度，列表头同步处理。
这些界面样式和联系信息分组不会改写业务字段。文档表格里的“对齐 / 背景 / 列宽 / 首行转表头”属于文档内容编辑，见后面的文档表格章节。
07

字段条件高亮与规则组

按状态、数量和日期识别记录，支持单元格或整行强调。

  1. 在快捷页打开条件高亮规则入口，或进入设置页的规则中心。
  2. 新建规则组，例如“协议跟进”“数据验证”；新建规则并命名。
  3. 选择当前表或全部表范围，指定目标字段，设置标准条件或高级表达式。
  4. 选择只高亮该单元格或整行；调整底色、透明度、边缘颜色 / 强度 / 宽度与文字加粗。整行可独立控制上、下强调边缘。
  5. 查看当前可见行匹配提示，按需调整优先级，点击“保存全部”。
  6. 开启总开关，确认规则所属组是当前生效组。用快捷页或 Alt+Shift+H 循环切换组。
条件类型 支持项
文字 包含、不包含、等于、不等于、开头是、结尾是、正则表达式；可选择区分大小写。
空值 为空、非空。
数值 大于、大于等于、小于、小于等于；比较时移除千位逗号。
日期 今天、昨天、明天、早于今天、晚于今天、未来 N 天内、过去 N 天内、指定日期。
高级 用受限表达式组合目标格和同行字段、文字、日期、数值与逻辑条件。

规则组、保存与优先级

同一时间只激活一个规则组，组内启用规则才参与高亮。管理器将规则组与规则列表分层呈现，支持组的创建、重命名、复制 / 删除以及规则的新建、复制、删除、分组和次序调整。修改在“保存全部”后统一生效，取消可放弃当前草稿。

组内规则从上到下判断，同一目标优先使用先命中的规则。聚焦模式优先于条件高亮。整行强调线在左置顶、主体和右置顶之间连续绘制，置顶底层保持不透明。

日期语义

日期按本机当天的本地午夜比较，忽略时分秒。可识别年-月-日、年/月/日、年.月.日及中文年月日；只有月日时使用当年。无效日期不命中日期规则。未来 N 天与过去 N 天条件均包含今天和第 N 天边界。

Alt+H 开关条件高亮；Alt+Shift+H 下一组；上一组默认无快捷键，可自行设置。停用总开关保留规则。旧版规则会迁移到默认规则组。

匹配数量反映当前可见虚拟行，不是后台所有记录统计。目标字段隐藏或尚未加载时，规则可能无法读取该值，应先显示字段再验证。
08

条件高亮高级表达式

用多字段条件表达更复杂的跟进场景。

高级高亮输入的是表达式本身，不加 {{= }} 包裹。结果转换为真假，真则命中；非法表达式可通过验证入口发现。解析器不执行任意 JavaScript，不支持访问 window、document、网络或存储。 

contains(field("进展描述"), "待验证") && field("二级阶段") != "已完成"

isPast(field("计划完成日期")) && !contains(field("一级阶段"), "完成")

num(value) > 0 && withinNextDays(field("有效期"), 7)
变量 / 函数 作用
value / fieldName / table 目标格内容、规则字段名、当前表名。
today / yesterday / tomorrow / now 日期午夜时间戳与当前时间戳。
field("名称") / row("名称") 读取同行字段。
contains / startsWith / endsWith / regex 文本包含、开头、结尾与正则检测。
lower / upper / trim / len / num / str 大小写、去空格、长度、数值与字符串转换。
empty / notEmpty 判断空值。
date / daysFromToday 日期转时间戳，与今天相差天数。
isToday / isYesterday / isTomorrow / isPast / isFuture 相对日期判断。
withinNextDays / withinPastDays 是否在未来 / 过去 N 天内，包含今天。
between / choose / coalesce 范围判断、条件分支、第一个非空值。

支持括号、字符串、数字、真假与空值，以及 == != === !== > >= < <= && || ! + - * / % ?:。这里的日期函数与快捷短语模板中的日期函数不同：高亮 date(value) 解析日期，短语 date(offset, format) 输出日期文字。

09

批量追加进展

在已选记录前添加新进展，保留原有历史。

  1. 在当前表勾选需要处理的记录，确保系统已选数量等于当前可处理数量。
  2. 点击快捷页“批量追加进展”，或按 Alt+B。当前表必须识别到“进展描述”字段。
  3. 输入本次新增进展，支持多行；使用“插入今日日期”或快捷短语补充内容。
  4. 检查第一条记录效果预览：新内容在最前面，后面换行接原历史。
  5. 点击“开始保存 N 条”，查看阶段、进度和成功 / 失败 / 跳过数量。
  6. 结束后核对结果；部分失败时先检查已保存记录，避免未经检查直接重跑。

保存方式与重复处理

当前实现复用 AutoTable 的原生记录保存接口，带记录版本校验逐条提交；不是模拟每条记录的双击、输入与失焦。运行前刷新已捕获的当前页记录，读取服务器原进展，再将新内容插到顶部。版本冲突时刷新并重试一次，避免用旧版本直接覆盖。

若新进展与原进展开头已一致，工具可跳过重复追加。运行过程中出现无法匹配记录、无权限、接口失败等情况，会计入失败并按当前流程停止或显示结果。

停止与范围限制

点击“停止后续”会等待当前记录保存完成，再停止后面的处理；已经保存的记录不会回滚。批量任务不是一笔整体事务，也没有全部撤销按钮。

如果系统已选 30 条，但当前页面只能定位 20 条，工具禁止开始，避免只处理部分记录。把记录移到当前页 / 可见范围，取消跨页或隐藏选择，必要时调整每页条数后重新勾选。

显示条件可读取当前字段名、同行其它字段、当前表格、当前内容、当前选中文本、星期和当前小时。只有同行字段需要指定目标字段名称。条件运算支持包含、不包含、等于、不等于、正则匹配、为空、非空、≥ 和 ≤。测试结果会显示实际值与每条条件是否通过；测试上下文取决于当前编辑位置。

系统短语与维护

默认系统短语包括：已确认该商业上线、已联系商业跟进、商业反馈处理中、商业暂未回复，已催促、已收到协议、协议已寄出、等待商业反馈、数据已回传，待验证、数据验证完成。系统规则可编辑、停用或恢复整条默认配置，不能直接删除；自定义规则可删除。

管理器支持搜索 / 筛选、批量选择、批量启停及批量编辑。批量编辑仅修改草稿，仍需主窗口“保存全部”。支持应用启用状态、使用场景、插入位置、编辑 / 批量日期前缀、日期时间格式与显示规则；显示条件可追加或替换，排序按现有值统一增减。还可在名称、模板或两者中执行批量文本替换，支持正则与区分大小写。只有勾选“应用”的属性才覆盖选中规则。规则数值越小越靠前；旧配置自动迁移到统一规则模型。

短语点击负责向编辑框插入内容；普通单条字段仍按 AutoTable 原生保存方式提交。“保存全部”保存的是短语配置，不是批量更新业务记录。

文档大纲、阅读记忆与书签

按章节和表格定位长文档，并保存常用位置。

大纲与两种导航模式

在文档设置开启自动文档大纲，左侧按 H1–H6 标题建立层级，标题与内容变化时更新。点击标题定位，点击箭头展开 / 折叠子章节。表格内标题不纳入普通章节大纲。无真实标题的加粗段落不会自动成为章节。

启用表格导航和合并层级后，表格入口归入所属标题；关闭合并层级后，表格单独显示，标题仍保留层级、折叠与标题标识。合并模式依赖自动大纲、表格导航及层级开关同时开启。

导航有搜索筛选、标题与表格 / 只看标题 / 只看表格三种显示范围；只看表格仍保留标题路径。支持全部展开、全部折叠和按标题层级折叠。大纲搜索只筛导航节点，不等同于正文查找。侧栏支持收起，大纲与书签使用分页式切换。

滑动跟随与记忆

开启大纲滑动跟随后，正文滚动会让当前章节在大纲可见区域中保持可见，已折叠章节保持收起。跳转仅滚动文档内部容器，减少整个页面抬升。可分别开启阅读位置与章节折叠记忆；两种导航模式共用章节折叠记忆。

自定义书签

  1. 先点击或选中文档中的目标内容。
  2. 在左侧“书签”页选择“＋书签”，填写名称并保存。
  3. 点击书签定位，使用修改名称、更新位置和删除入口维护。
  4. 正文结构改变、内容匹配不明确时，点击新的正确位置，再更新该书签锚点。
书签独立开关关闭后保留已有书签。每个文档最多 200 个书签，名称最多 120 字符。书签基于内容和位置定位，正文被删除或大幅修改后可能需要重新锚定。

文档查找、正则与替换预览

在全文或锁定范围内查找，并在批量修改前确认结果。

  1. 在文档原生工具栏点击“查找”，展开紧凑查找栏；替换输入默认折叠，需要时展开。
  2. 输入关键词，按需开启 Aa 区分大小写或 .* 正则模式。
  3. 使用上一个 / 下一个 / 定位查看匹配项；浏览器支持时正文高亮全部匹配和当前匹配。
  4. 选择全文、当前章节、当前表格或选区。先在正文定位或选择，再点“更新范围”锁定正确区域。
  5. 单次替换处理当前匹配；批量替换打开预览，检查旧值、新值、范围和处数后确认。

锁定范围

除全文之外，范围取自当前章节 / 表格 / 选区并锁定。之后点击别处不会自动把范围换成新的位置；使用“更新范围”重新选择。出现“范围为空”时先点击正文、目标表格或选择文本，再更新范围。

正则替换

查找表达式填入输入框，不需要加 JavaScript 的外层斜杠。替换支持 $1…$99 数字捕获组、$& 整个匹配、$<name> 命名捕获和 $$ 字面美元符。语法错误即时提示并阻止执行；可匹配空字符串的正则禁用全部替换，避免异常插入。 

查找：(BRL)(\d{6})
替换：$1-$2
示例：BRL000621 → BRL-000621

预览和撤销

批量替换单次最多收集 5000 处，预览分批显示，可点“显示更多”。确认前若正文、文档或锁定范围已变化，会要求重新预览；重叠匹配不能批量提交。可用模型事务提交时，统一替换可通过一次原生撤销恢复。缺少可用编辑器或 schema 能力时入口会提示不可执行。

匹配数量正确但没有颜色时，可能是浏览器不支持 CSS Custom Highlight API。只读文档可以定位与查找；替换仍受编辑权限和原编辑器能力限制。

四方向插入 当前行上方 / 下方插入行，当前列左侧 / 右侧插入列；末尾加号快速扩展。
删除行 / 列 按当前选择调用原生能力；合并格跨度同步校验，不支持的结构提示。
合并单元格 对符合要求的连续矩形选区合并，优先原生命令，不可用时使用跨度校验的模型适配。
拆分单元格 将当前合并格按模型跨度恢复为相应结构。
清空选区内容 清除选区单元格内容，保留表格区域结构。
行列排序 拖动行 / 列数字柄；也可通过当前行上移 / 下移、当前列左移 / 右移入口移动。
合并格分组移动 与合并格跨度相连的行或列作为一组移动，避免拆坏合并结构。
删除整个表格 需要短时间内再次点击确认。确认针对当前表格与入口。

所有内容修改通过原生 commands 或 schema 校验后的 transaction 进行，不靠直接改表格 DOM 冒充保存。模型适配会检查尺寸、跨度和结构；超过处理范围或结构异常时停止并提示。操作是否可用以当前选区和原编辑器的能力为准。

文档表格结构操作会修改文档。优先用编辑器的原生撤销恢复误操作；撤销只覆盖原编辑器中的文档变更，不会回滚业务表的批量进展。

文档表格：区域复制与矩形粘贴

在 AutoTable 文档与 Excel / WPS 之间交换二维区域。

  1. 在文档表格内选择矩形多格区域，使用原生复制或“复制区域（TSV / HTML）”。
  2. 在 Excel / WPS 中粘贴，可按接收软件支持使用二维文字；复制到富文本软件可保留 HTML 表格结构。
  3. 从 Excel / WPS 复制矩形区域，在文档目标格或多格选区粘贴。
  4. 如果内容超出表格边界，确认是否扩行 / 扩列；如果覆盖已有合并格，确认是否拆分。
  5. 粘贴完成检查区域、合并跨度和周围旧内容，必要时原生撤销。

合并格与限制

区域复制同时提供 TSV 与 HTML。TSV 使用制表符和换行表达二维数据；HTML 可表达合并格结构。粘贴根据剪贴板数据与编辑器能力进行矩形写入、扩展与跨度校验，支持合并格粘贴及后续行列编辑。

单次表格处理的单元格上限为 10000，用于限制模型 / 粘贴范围；并不是建议把一万个格一次性写入。结构异常、跨度越界、尺寸过大或能力不可用会提示停止。浏览器剪贴板权限和接收软件支持会影响格式保留。

业务表的字段组合 Tab 复制只是同行字段文字输出，不带文档表格的合并结构；文档矩形粘贴也不会直接导入业务数据表。

常见问题与排查

从前提、开关、上下文到原页面能力逐项检查。

页面上没有悬浮球？

检查脚本已安装并启用，页面地址匹配附件的两个 IP，且刷新后的页面正常加载。自定义域名不在附件匹配范围。确认没有同时启用多个版本。

普通点击为什么没有复制？

当前设计为普通点击仅聚焦。复制当前格用 Alt + 单击，字段组合用 Ctrl + 单击，并确保智能复制已开启。

字段组合少了一项或复制错字段？

查看组合兼容提示；检查当前表字段 ID 绑定和通用模板名称匹配，字段是否隐藏 / 未加载。为当前实际表重新保存专用配置通常更可靠。

置顶没有生效或位置异常？

检查总开关、当前表配置与当前视图字段可见性，点击重新应用。宽度不合理时清除列宽记忆再拖动；左右置顶过多会压缩中间区域。

高亮规则已启用却没有颜色？

检查总开关、当前生效规则组、目标表范围、字段读取和条件值。聚焦视觉优先；匹配数量仅针对可见行。修改草稿后需要保存全部。

批量保存按钮灰色或拒绝开始？

检查“进展描述”字段与权限，确认有勾选记录；系统已选与可处理数量不同会禁止开始。将选择限制在当前页可处理记录，再试。

批量停止后已修改记录会恢复吗？

不会。停止仅停止后续处理，已保存记录保留。先核对成功记录与结果，再决定怎样修正剩余记录。

快捷短语没有出现？

检查快捷短语总开关、目标是否为可识别的多行编辑字段、规则启用和使用场景、显示条件及保存状态。普通单行字段不保证出现多行快捷面板。

插入了两次日期？

检查模板是否已有 {{today}}，同时是否开启编辑 / 批量日期前缀或其它模板内日期变量。按任务取消额外前缀，避免叠加。

搜索词为什么没被记录？

默认只在原生搜索实际生效或 Enter 时记录。仅输入后离开不会默认保留；需要草稿历史可开启失焦或停止输入条件。

胶囊没有删除按钮，还能删除吗？

胶囊 × 可独立关闭；列表、原位展开的全部记录和搜索记录管理仍保留删除能力。

文档大纲没有标题或跳转不正确？

正文需要真实 H1–H6 标题，不是仅加粗段落。检查自动大纲与对应导航开关；标题 / 内容大幅修改后刷新大纲并重新定位。

书签找不到原位置？

正文可能被移动、删除或多处重复。点击正确的新位置，再使用书签更新位置入口重新锚定。

查找显示“范围为空”或只搜到部分内容？

非全文范围会锁定。先点击章节、表格或选中文本，再更新范围；想搜整篇请切换全文。

正则替换按钮不能点？

检查正则语法，是否匹配空字符串、文档是否只读，以及当前编辑器是否支持模型提交。正文或范围在预览后变化需重新预览。

文档表格合并、排序或粘贴失败？

检查选区是否为同表矩形、合并跨度是否一致、处理尺寸是否超过上限，以及原编辑器命令 / schema 是否支持。结构异常时工具会阻止提交。

右键菜单与浏览器菜单怎样切换？

表格右键增强开启时直接右键显示工具菜单；Shift + 右键使用浏览器菜单，也可关闭右键子开关。

打开深色优化后界面没变化？

先检查 AutoTable 原生是否处于深色模式。工具只在原生深色模式接管配色，浅色模式保持原主题。

导入备份后为什么刷新？

各模块独立读入持久化配置，统一刷新使它们同时使用恢复的设置。导入前应完成原页面未保存内容。

性能与技术排查

工具对虚拟行采用增量处理，菜单按可见分区刷新，字段与上下文做缓存。文档表格使用事件委托与逐帧合并，不增加持续轮询。这些是工作机制，不代表在任何数据规模或浏览器下都没有开销。

高级排查可在页面控制台读取以下诊断对象。默认诊断完全不可见，不增加普通用户菜单；部分模块版本仍保留历史标记。 

__attPerfStats.summary()   // 简要统计
__attPerfStats.snapshot()  // 完整计数与耗时
__attPerfStats.reset()     // 重置后重新比较

统计包括面板重绘、上下文刷新合并、缓存命中、置顶应用、条件高亮处理量与批次耗时。它是本页诊断，不是服务器监控。排查前记录页面、场景、脚本版本和可复现操作，比只提供“卡顿”更便于定位。
